Hand Frame FX — Windows XP Edition
Real-time hand tracking that turns your webcam into a special-effects camera — running inside a hand-made Windows XP desktop, in pure HTML/CSS/JS.

Demo · Screenshots · Getting Started

💡 What it does
Raise both hands in front of the camera — a glowing frame is formed between your fingertips(the quad between the thumb & index tips, tracked by MediaPipe).

🖼️ Everything inside the frame gets a live visual effect
🌑 Everything outside fades into a dark blur
🤙 Pinch your thumb + index finger to switch to the next effect
🎨 Pick the frame color from the classic MS Paint palette
Everything runs locally in the browser — no server, no build step, a single index.html.
